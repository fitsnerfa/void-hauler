# VOID HAULER --- Instruction Manual (v1.4.1)

## Version 1.4.1 Highlights

-   Added **Quest Journal** (`J`)
-   Added **Crew Equipment** system
-   Added **Armory** (10 item storage)
-   Added **Best Equipment Config**
-   Added **Unequip All**
-   Added **Equipment Upgrades** (maximum **+5**)
-   Duplicate equipment converts into **Upgrade Points**
-   Elite enemies may drop **+1** equipment
-   Pirate Bosses may drop unique **+2** equipment
-   Pirate Hideouts are permanently cleared after completion
-   Updated version numbers throughout

------------------------------------------------------------------------

## Controls

  Key                    Action
  ---------------------- --------------------------
  **W / ↑**              Thrust forward
  **S / ↓**              Reverse thrust
  **A / D** or **←/→**   Turn
  **SPACE**              Fire Mining Laser
  **SHIFT**              Tractor Beam / Ram Scoop
  **Z**                  Fire Missile
  **E**                  Dock / Activate Stargate
  **I**                  Cargo Manifest
  **J**                  Quest Journal
  **ESC**                Close menus

> **Note:** CTRL is no longer used for the Tractor Beam.

------------------------------------------------------------------------

## Quest Journal

Press **J** to open the Quest Journal.

The journal displays: - Active quests - Completed quests (✓) - Current
objectives - Progress counters

------------------------------------------------------------------------

## Crew Equipment

Each crew member has four equipment slots:

-   Armor
-   Melee Weapon
-   Ranged Weapon
-   Special Item

Equipment is managed from the Armory.

------------------------------------------------------------------------

## Armory

-   Stores up to **10 unequipped items**
-   **Best Equipment Config** automatically equips the strongest gear.
-   **Unequip All** removes all equipped gear.
-   If the Armory is full, you must either equip the new item or convert
    one into Upgrade Points.

No dropping or selling equipment.

------------------------------------------------------------------------

## Upgrade Points

-   Normal equipment = **1 Upgrade Point**
-   Upgraded equipment = **2 Upgrade Points**
-   **10 Upgrade Points** = one equipment upgrade
-   Maximum equipment level is **+5**

------------------------------------------------------------------------

## Equipment Drops

-   Normal enemies: Common equipment
-   Elite enemies: May drop **+1** equipment
-   Pirate Bosses: May drop unique **+2** equipment

------------------------------------------------------------------------

## Pirate Hideouts

Pirate Hideouts are one-time encounters.

Once cleared: - Bosses do not respawn. - Chests remain opened. - The
hideout remains permanently cleared.
